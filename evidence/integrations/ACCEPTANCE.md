容器使用 Ubuntu 26.04、固定版本第三方服务和生产依赖。全新七服务实例通过健康门槛，恢复实例另行启动并验证。验证中修正备份卷初始目录的属主、恢复后私有文件属主，以及服务复制软链接；源码保留修复。源码与打包文档后续仍需随新包解压复测。

资源管理：旧 QA 栈已停。本轮应用与恢复测试栈、专属浏览器、Docker 守护服务均在测试后关闭；数据卷和私有备份保留。容器设置逐服务内存上限；embedding 默认单并发、有界等待，子进程完成即释放。没有关闭用户原有服务或读取用户浏览器。

边界：这是同一主机的隔离自动化验证。真实学校运营、目标 Ubuntu 服务器、DNS/TLS、SMTP 到达、真实外部合作方履约均未在本轮验证。公开接待与受控私有历史分开，个人 Agent 长期记忆未开发，P2 未开展。新提供的运营材料另行分析与补全，不由本条验证宣称完成。
